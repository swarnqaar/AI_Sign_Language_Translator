# 🤟 AI Sign Language Translator

An AI-powered real-time Sign Language Translator that converts hand gestures into text and speech using Deep Learning, Computer Vision, and NLP techniques.

---

# 📌 Project Overview

This project helps bridge the communication gap between deaf/mute individuals and non-sign-language users by translating sign language gestures into readable text and audio output.

The system uses:
- Computer Vision for hand detection
- Deep Learning for gesture recognition
- Speech synthesis for voice output

---

# 🚀 Features

✅ Real-time hand gesture detection  
✅ Sign Language → Text conversion  
✅ Text → Speech output  
✅ Webcam-based prediction  
✅ Deep Learning gesture recognition  
✅ Interactive Streamlit UI  
✅ Supports custom gesture training  
✅ Scalable for sentence prediction
